# Атаки ближнего боя третьего акта

Настройки слоёв: `profiles.py`. Подключение: общий `ActThreeSoundBank`.

Ассеты остаются в `assets/audio/sounds_act_3/player/<subclass>/attack/`.
Загружаются MP3 непосредственно из папки слоя. Вложенные `old` не загружаются.
Имена файлов свободные; варианты перемешиваются без повторов до завершения цикла и без немедленного повтора между циклами.

## Ассасин

- `hit`: новый кинжал при контакте, включая блок щитом.
- `miss`: взмах при атаке без контакта, включая уклонение врага.
- Shadow Reflex использует тот же кинжал; дистанционная контратака учитывает задержку выпуска и полёта.
- Killing Spree сохраняет собственный звук и не запускает обычный кинжал вторым слоем.

## Берсерк

- При контакте: случайный готовый файл из `attack/hit`, уровень 0.38 до общей громкости Effects.
- При промахе: только `attack/miss`, уровень 0.26.
- Старые отдельные слои больше не загружаются: готовые файлы уже содержат нужный микс.

Обычный контакт назначен на 45% анимации атаки (144 мс из 320 мс). Это стартовая настройка для ручной подгонки под записи, а не результат прослушивания.
Очередь очищается при смерти или смене персонажа; сильно просроченные звуки не воспроизводятся после паузы.
Система сейчас обрабатывает обычные атаки и Shadow Reflex. Вращение, Power Cleave и остальные способности не получают слои обычной атаки автоматически.
Исходные записи не изменены. Для эффектов доступно минимум 16 каналов микшера.

Игра и тесты при подключении не запускались.
