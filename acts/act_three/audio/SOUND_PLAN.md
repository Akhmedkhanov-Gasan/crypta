# Звуковой план третьего акта

Корень ассетов: `assets/audio/sounds_act_3/`.
План охватывает третий акт, включая используемые им общие механики. Первый и второй акты сохраняют свои банки и ассеты.
Созданная папка означает место для будущих записей, а не подключённый звук.

## Эталон шагов

Сохранять существующие `movement_timing.py` и `audio/footsteps/`.
Сейчас шаг занимает 220 мс; удержание постановки ноги — 25 мс, удержание позы — 60 мс.
Звук назначается на `started_at + player_footfall_delay(step_ms)` и воспроизводится через обновление банка.
Для обычного шага контакт приходится на 195 мс; для другого направления используется рассчитанная длительность перемещения.
Ожидающий звук отменяется при смерти, специальном перемещении, прерывании атакой или получением урона.
Варианты перемешиваются без немедленного повтора; лимит — четыре голоса.
Другие материалы используют тот же механизм. Менять тайминги ради нового файла не нужно: подготавливать начало записи под текущий контакт.
`light_leather` уже используется ассасином и лучником. `heavy_armor`, `cloth`, `demon` — будущие категории; назначение остальных классов ещё не подключено.

## Правила подготовки

- Один файл — один законченный базовый звук события. Foley и многослойное смешивание пока не нужны.
- Для частых звуков желательно 6–8 вариантов, для редких — 2–4, для уникальных сигналов достаточно одного.
- Имена новых файлов: `<event>_01.mp3`, `<event>_02.mp3`. Для шагов сохранять `<category>_01.mp3`.
- Односоставные действия могут использовать один общий файл: не требуется отдельная запись для каждой руны, каждого критического попадания или каждого типа предмета.
- Продолжительные звуки `burning`, `dungeon`, `torch`, `work` при реализации должны иметь управляемый запуск и остановку. Это не обязательная часть первого набора.
- Отдельную озвучку реплик записывать после стабилизации текста. Базовые приветствия могут быть короткими невербальными звуками.

| `player/magic/summoner_bolt/cast`, `hit` | Обычная атака призывателя и попадание |
| `player/magic/demon/attack` | Атака демонической формы |
| `player/combat/dodge` | Уклонение |
| `player/combat/block` | Полный блок щитом/защитой |

`shoot` и `hit` — разные события во времени, а не требование накладывать несколько слоёв на один звук.

## Способности

Общие папки: `player/shared_abilities/power_cleave`, `invisibility`, `arcane_burst`.
Существующий инвиз пока остаётся в `player/assassin/skills/invisibility`; новую общую папку можно заполнить при следующем наборе.

| Подкласс / папка в `player/<subclass>/skills/` | События |
| --- | --- |
| `berserker/rending_spin` | Начало рывка-вращения, удар; нынешнее название способности Rending Spin, хотя в коде встречается crushing_leap |
| `berserker/last_rage` | Включение ярости, поглощение защищённого удара, окончание |
| `paladin/shield_charge` | Старт разгона, столкновение щитом |
| `paladin/sacred_ground` | Вонзание клинка, появление зоны, чёрная молния при попадании, окончание |
| `assassin/shadow_step` | Исчезновение/возвращение, уже есть |
| `assassin/invisibility` | Вход/выход, уже есть |
| `assassin/killing_spree` | Удары и `target`, уже есть |
| `archer/piercing_shot` | Усиленный выстрел, пробитие |
| `archer/phantom_retinue` | Призыв и исчезновение призрачной свиты; выстрелы можно переиспользовать |
| `warlock/curse` | Наложение и окончание проклятия |
| `warlock/demon_form` | Превращение и обратное превращение; потеря здоровья и лечение используют общие события |
| `summoner/summon_familiar` | Вызов и отзыв; переиспользовать звуки companion, не запускать дважды |
| `summoner/greater_manifestation` | Призыв и развеивание большого духа; переиспользовать companion |

Power Cleave: широкий удар и повторный удар Aftershock. Arcane Burst: выпуск/взрыв.
Фазы одной способности сначала могут использовать один законченный звук; отдельные варианты понадобятся только при раздельном воспроизведении.

## Руны: отдельные записи только при слышимом новом действии

Папки: `player/runes/<rune_id>/`. Все реализованные руны Q/F и общие руны E имеют места под ассеты.

- Assassin: Displacement — обмен местами/оглушение; Doppelganger — обычный инвиз; Carnage — дополнительные обычные удары серии; Executioner — более тяжёлый вариант удара по одной цели.
- Archer: Emerald Piercing Shot — магическое пробитие/оглушение; Splitfang Arrow — разделение стрелы; Spectral Archers — обычный призыв; Phantom Archer — появление двойника, его действия переиспользуют оружие и инвиз.
- Berserker: Blood Wheel — наложение кровотечения; Devastation — финальное вращение; Second Wind — выпуск накопленного лечения; Death Wish — опасное включение ярости. Не озвучивать каждый прирост счётчика.
- Paladin: Battering Ram — столкновение; Tower Shield — обычный блок; Fervent Crusade — усиление оружия/окончание; Redeeming Sanctuary — попадание зоны и лечение.
- Warlock: Spreading Curse — перенос проклятия; Madness — наложение безумия; Eternal Form — превращение; Blood Pact — включение договора, остальное переиспользует форму/лечение.
- Summoner: Spirit Totem — постановка/разрушение тотема, его выстрел; Possession — вход духа в носителя/перенос; Soul Devourer — поглощение души; Absorption — поглощение большого духа и окончание усиления.
- Общие: Impact — блок; Reaping — восстановление заряда, необязательный отдельный сигнал; Aftershock — повторный удар; Shade/Veil — инвиз; Cruelty — кровотечение; Fracture — площадной взрыв; Resonance — магическая атака; Concentration — точечный взрыв.

## Союзники

- `companions/familiar/{summon,move,attack,hurt,death,recall}`: появление, перемещение, атака/рык, боль, гибель, отзыв.
- `companions/greater_spirit/{summon,move,attack,hurt,death,dismiss}`: то же для большого духа, с более тяжёлой атакой.
- `companions/phantom/{appear,shoot,disappear}`: призрачные лучники и двойник. Отдельная боль нужна только если появится соответствующее событие.
- Одержимый противник может переиспользовать движения/атаки своего вида; отдельного полного набора не требуется.

## Противники

Для `goblin`, `archer`, `brute`, `sentinel`, `priest`, `priest_ghost`, `mimic`, `lantern_warden` созданы `{move,aggro,prepare,attack,hurt,death}`.
Не все эти состояния обязательно должны звучать часто. Для первого прохода нужны prepare/attack/hurt/death; move и aggro — позже.

- Goblin: обычная атака и `summon` для вызова подкрепления.
- Archer: подготовка выстрела, выпуск стрелы, попадание можно переиспользовать из общего оружия.
- Brute: тяжёлая подготовка, удар, `aftershock` для последействия.
- Sentinel: `block`, `shield_bash`, `shield_counter`.
- Priest: `heal`, `rebirth`; призрачная форма — собственные боль/смерть или обработанные варианты.
- Mimic: `awaken` для раскрытия сундука, укус/атака.
- Lantern Warden: `awaken`, `lantern_sweep`, `soul_lance`, `cinder_nova`, `soul_procession`; для каждой способности сначала один цельный звук. У Soul Procession нужны читаемые предупреждение/срабатывание, чтобы игрок различал опасность.

Ранее записанные звуки врагов второго акта остаются в `sounds_act_2`: это кандидаты на переиспользование, не обязательная перезапись.

## Предметы и мир

- `items/potion/use`: выпивание/лечение.
- `items/fire_bomb/{throw,break,ignite,burning}`: бросок, разбитие, воспламенение, горение.
- `items/scrolls/{stoneflesh,binding,healing,arcane_impulse}`: применение четырёх свитков.
- `items/pickup/{gold,consumable,key,ore,special}`: подбор; специальное — кирка, печать гильдии, ключ склепа.
- `items/inventory/{move,drop,keyring}`: перемещение предмета, выбрасывание, добавление ключа в связку.
- `environment/chest/{open,locked}`: открытие, попытка открыть запертый сундук.
- `environment/crates/break`, `secret_wall/break`: разрушение объектов и секретного прохода; общий деревянный/каменный звук можно переиспользовать.
- `environment/doors/{open,close}`, `stairs`: двери, переход между этажами.
- `environment/altar/{activate,upgrade}`: вход во взаимодействие, получение улучшения.
- `environment/mining/{strike,depleted}`: удар киркой и разрушение жилы. Iron/Black/Bloodvein сначала используют общий набор, отдельная магия руды позже.
- `environment/ambience/{torch,dungeon}`: необязательный тихий фон, позже.

## NPC, прогресс и интерфейс

- `npcs/blacksmith/{work,greeting,forge}`: работа молотом, начало общения, ковка/закалка. Только реально доступные ранги улучшений; будущие рецепты не требуют новых звуков сейчас.
- `npcs/trader/{greeting,buy,sell}`: встреча, покупка, продажа.
- `npcs/rune_master/{greeting,inscribe}`: встреча, нанесение/смена руны.
- `progression/quest/{accept,update,complete}`: начало, важный прогресс, завершение квеста.
- `progression/trials/{enter,start,success,failure,exit}`: общие сигналы шести классовых испытаний. Способности и враги внутри используют свои обычные звуки.
- `ui/{hover,confirm,cancel,error}`, `ui/panel/{open,close}`, `ui/dialogue/advance`: навигация, подтверждение, отмена, недоступное действие, окна, перелистывание реплик. Hover/advance необязательны; избегать постоянного звукового шума.
- Персонажные реплики для кузнеца, торговца, мастера рун, квестов и испытаний — отдельный будущий проход озвучки, не часть базового SFX.

## Порядок производства

1. Кинжал, меч, лук, две базовые магические атаки; затем боль/смерть остальных персонажей.
2. Шаги других материалов с неизменным механизмом контакта ноги.
3. Враги: предупреждения и атаки, затем боль/смерть; Lantern Warden отдельно.
4. Базовые Q/E/F всех классов и компаньоны.
5. Предметы, сундуки, добыча руды, кузница, покупки и улучшения.
6. Отличающиеся действия рун, испытания, интерфейс.
7. Только затем ambience, Foley и многослойные варианты.

Пустые папки существуют локально. Git не хранит пустые каталоги; при наполнении они попадут в историю вместе с файлами.
